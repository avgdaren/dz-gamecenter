## 试玩

在仓库根目录运行：

```powershell
python tests/danmaku/serve.py --port 8876
```

打开 <http://127.0.0.1:8876/>。预览只绑定本机，且只服务明确白名单内的静态文件，不开放 PHP、Git 或工作区其他文件。端口已被其他实例占用时，应停止自己的旧实例或换一个端口，不要启动两个相同端口的服务。

键盘：方向键／WASD 移动、Shift 慢速、X／空格清屏、Esc 暂停。支持相对拖动和独立清屏按钮。选择其他场景会重置当前练习。后台或失焦自动暂停；确认后经过倒计时继续。自然结束后可导出回放，在页面折叠区做浏览器复验，或用下面的 PHP 命令重算。

## 规则与回放检查

需要现有 Node.js、PHP 8.3、Python 3，不需要安装 npm 包或构建。默认 PHP 路径是本机 `E:\dzx5-env\php\php.exe`，其他机器可通过本次命令的环境变量指定：

```powershell
$env:DANMAKU_PHP = 'E:\dzx5-env\php\php.exe'
node tests/danmaku/test-core.cjs
```

覆盖碰撞切线／扫掠、移动上限、瞄准锁定、发射时点、无敌截止步、同帧优先级、擦弹去重、资源消耗与终局；生成 6 份自然终局样本，并运行 200 组固定种子合法输入的 JS/PHP 差分，每 60 步及终局逐项比较完整状态。另拒绝 13 类非法／非终局记录；单独检查 Base64 非规范填充位。

验证实际浏览器导出的文件：

```powershell
node tests/danmaku/check-export.cjs 'C:\path\danmaku-flower-2700-p0.json'
```

直接用 PHP 重算：

```powershell
& 'E:\dzx5-env\php\php.exe' tests/danmaku/cli.php 'C:\path\danmaku-flower-2700-p0.json'
```

CLI 自身有 8 MiB 的本机批处理输入上限，单场原型回放最多 2,700 步／18,000 Base64 字节；浏览器选文件在解析前检查 256 KiB 上限。原型 PHP 文件均拒绝 HTTP 执行，不能将测试 CLI 当作正式成绩接口。

## 性能

先运行规则检查生成正常记录，再运行：

```powershell
& 'E:\dzx5-env\php\php.exe' tests/danmaku/benchmark-normal.php
& 'E:\dzx5-env\php\php.exe' tests/danmaku/benchmark.php 0 1
```

第一条先筛查六份合法原型样本，选首轮最慢者预热 5 次、测 50 次，包括解码和每 60 步的诊断快照。第二条仅做一次极端压力筛查；正式 5 次预热＋50 样本可去掉参数，但本轮已确认超预算，没有继续消耗大量时间重复失败夹具。

极端夹具是 360 颗常驻、持续重新擦弹的人工粒子，强行延长寿命并运行 13,200 步，不是合法标准局。它不能经原型回放选择，也不能证明正常用户能生成这种弹幕。

## 本轮结果（2026-11-10）

- Node.js 24.19.0、PHP 8.3.36 CLI、Intel Core i9-14900HX；`opcache.enable_cli=0`。本机同时有日常应用，未做隔离硬件或线上容量承诺。
- 35 项边界／往返／拒绝检查、6 份正常终局、200 组随机自然终局差分、13 类两端非法拒绝通过。合法输入不是从客户端状态重建，PHP 重算全部位置与资源。
- 实际浏览器花瓣场 2,700 步导出记录，通过 Node 与 PHP 每 60 步的完整状态对照；终局 192 次命中／1 次受击／3 次擦弹／1 次清屏，与页面结果相符。记录包含移动，非全零输入。
- 正常原型最慢样本为辅助花瓣场，50 样本 p50=145.12ms、p95=150.51ms、最大 151.70ms，PHP 峰值内存 4 MiB，满足正常原型的 500ms 筛查目标。
- 极端非合法夹具初测 4054.50ms；优化扫掠包围盒排除后，默认 CLI 复测 3783.47ms，仍超 500ms 目标。单次筛查，不称为稳定 p95。完整 P0 性能门槛尚未通过。
- 真实浏览器已操作花瓣／连射／波浪场景、清屏、暂停／继续、相对拖动；花瓣与波浪各完成过 45 秒。360×800 窄屏与 1280×900 桌面断点已实际渲染，无水平溢出；桌面操作区底部在视口内。暂停前后剩余时间均为 10.4 秒。
- JS／PHP 语法、JSON 加载通过。尚未进行实际手机双指、完整三阶段战役、真人难度统计、PHP worker 混合负载、论坛开局与榜单、正式美术或音频验收。
