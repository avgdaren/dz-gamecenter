# Portable deterministic fixtures

(C) 2026 Carinoasd; fixture preparation: 小典 / Codex.

The r2 input was generated by the earlier automated browser QA, not by a real player. It contains only bounded gameplay input and score/version fields, with no identity, cookies, tokens, URLs or browser profile. The six legacy verifier files were read from the preserved stage01-show-v1 delivery so r2 compatibility can be checked after cloning without depending on this machine's tmp/output folders. They retain their original headers.

These are offline test fixtures, not forum submissions or new natural-play runs.

`normal-v1-snapshots.json` records SHA256 hashes of 14 bounded Normal v1 traces from commit `2b61ba83e4c27472f46e0314e1ef926fdebb05a3`, before the Boss v2 and respawn-bomb changes. Its inputs are the fixed 960-step local test pattern, not player data; no image/audio or browser profile is duplicated.

`legacy-stage01-r3/` freezes the eight simulation/config files from handoff commit `50b6d415155d8d3140a8e6066dbc7d31e990a0ae`. Normal tests compare old rules against this accepted implementation without depending on local ZIPs, launching a browser, or duplicating images/audio.

Run `node tests/danmaku/test-handoff-bridge.cjs` and `node tests/danmaku/test-boss-r3.cjs` with Node and PHP 8 on PATH. If PHP is elsewhere, set `DANMAKU_PHP` to its executable path first. No npm install is needed. Older packaging/audit scripts still reference local historical output; those delivery ZIPs are not dependencies of these two checks.
