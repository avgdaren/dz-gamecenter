## 启动与关闭

需要 PHP 8.3 CLI、Python 3.10+；测试前台状态另外需要 Node.js 18+。全部使用标准库，无 npm 安装、CDN 或构建步骤。

在仓库根执行（本机 PHP 未加 PATH 时，用实际 php.exe 路径）：

```powershell
python tests/raid/serve.py --php E:\dzx5-env\php\php.exe
```

浏览器打开 `http://127.0.0.1:8093`。可用 `--port 8094` 更换端口。CLI PHP 路径以实际安装为准，不依赖示例路径一定存在。

Linux / macOS：

```sh
python3 tests/raid/serve.py --php php
```

启动器在系统临时目录创建独立 session 存储，关闭服务时清理；不会向源码树写用户状态。Ctrl+C 关闭即可回退，无插件部署、数据库迁移或卸载动作。保持终端开启；不要绑定公网地址、放到线上 nginx 或把它当正式 API。

路由仅在 PHP 内置开发服务器运行，且只接受回环访问、正确 Host 与同源请求。仅公开四个静态资源和本机 `/api`，不会代理仓库文件。每个浏览器 session 独立；复制网址到另一个浏览器不会加入同一战斗。两个标签共享同一 session，适合刷新／重复提交测试，不等于两个论坛账号。

## 玩法与试玩顺序

1. 先选“双席位模拟”：观察首领预告，为两个席位分别选择行动并确认。第一人确认后意图可见，第二人仍能对同一回合确认。双方锁定即结算。
2. 体验一次“守护队友”：被点名者继续攻击，另一人守护他。星潮是全体伤害，守护队友不会同时保护自己。
3. 重击成功守护且目标存活，下一轮回气有破绽，攻击 20；其余攻击 10。预告中的原伤害与守护后伤害会同时显示。
4. 再尝试单人：恢复治疗 28、封顶 40，最多 3 次；不是双人模式少开一个操作面板。失败后检查战斗记录，再试一次。
5. 满血恢复、无次数、倒地、离场、锁定、终局等操作会禁用；服务器还会独立校验。恢复在结算时扣，确认但未结算时次数不变。多人治疗同一目标均消耗，界面会提示溢出。
6. “跳到本轮截止”是样稿辅助：服务端把模拟时钟跳到原 deadline，仅给未确认的存活席位补“守护自己”；已确认行动照常执行。“模拟离线 400 秒”连续追算，原截止不延长，最终不会靠默认行动获胜。这些按钮只存在于本地样稿，P2 不接收客户端时间。
7. 试刷新、关闭再打开、首次连接失败重试。操作响应丢失时，保留未确认请求，禁用新命令；“重试上次操作”沿用原 ID。浏览器 sessionStorage 可用时，刷新后仍能重试；不可用时只保证当前页面内重试。
8. 单人撤退立即失败；双人撤退需确认，锁定的动作保留，否则守护自己，本轮结束后离场。最后一击先于首领和回合后离场，获胜轮取消未发生的离场；这条边界已单独测试。

界面有浅色／深色、320px 起的响应式布局、键盘原生按钮与表单、状态播报、减少动态效果支持。**这些布局与触控能力尚待真实浏览器验证，不能根据 CSS 和 DOM 子集测试判为验收通过。** 图像是本地 SVG 轮廓占位，不是最终插画，也没有引入新主角设计。

## 纯规则接口与 P2 交接

`gamecenter_raid_rules::initial(mode, now)` 仅接受固定模式；服务器生成上限、生命与恢复预算，模式不随倒地／离场改变。`validate` 检查版本、结构、取值和活动预告。`submit(state, round, actor, {kind,target}, now)` 按 round 锁定意图，不要求双方携带相同全局 version。`advance_due(state, now)` 按原 deadline 有界追算最多 16 轮。`retreat` 实现回合后离场。输入/状态错误抛 InvalidArgumentException，调用方映射为稳定的业务错误；不把 PHP 异常内容直接回显给正式客户端。

服务层必须在房间锁内取服务器时间，先执行并持久化 `advance_due`，再校验迟到的行动；不能因为行动被拒就回滚已经完成的到期结算。本机路由演示了这条调用顺序，但正式 P2 还要正确处理 DB 事务及幂等回执。

`history` 最多 16 条，纯座位/枚举/数值，不带 UID、昵称或 URL；P2 入库仍必须做 UTF-8 JSON_THROW_ON_ERROR 编解码、整段 16384 字节／摘要 512 字节检查、身份与成员权限、三表事务和查询安全测试。不要把本机原型的 session、clock offset、generation 或两席位控制直接变成论坛授权协议。

P2 继续完成三表、op=raid、账号／房间／邀请／幂等／刷新／截止和个人记录；P3 才做最终插画与体验完善；P4 再做真实论坛容量、完整升级/回退及旧游戏回归。原 SDK、memory、snake、gomoku 和现有表都未改。
