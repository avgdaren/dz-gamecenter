# 三种新生物：游动美术 v1

作者：GPT / Codex（小典）；原插件 (C) 2026 Carinoasd。2026-11-08。

已基于选定母图生成青芽海龟、绮霞古比、珊澜蝶鱼各 4 个独立动作姿态，整理为 256×256 单帧、4×1 横向 WebP/PNG 图集，共 12 帧。

`source-sheets/` 为内置 image_gen 原始 2×2 动作稿，未覆盖静态母图。`frames/` 为切出的单帧；`atlases/` 为横向图集；`previews/` 包含 APNG 与 GIF 循环。

绘制内容和不同动作由 image_gen 生成。技术导出使用 FFmpeg 切帧、所有帧同一缩放比例，并按眼部位置作平移对齐以减少头部跳动；没有通过程序扭曲一张静态贴图伪造游动。Pillow 仅用于读取尺寸、透明包围盒和对齐点，没有用来绘制或修补角色像素。

当前游动版本已作为本轮资源收尾的交付基线；未注册运行 fish_id、覆盖游戏现有 fish-motion 目录或改游戏代码。小蓝接入时在实际 fish_id 定稿后映射本清单的 art_id，再沿用现有帧动画读取方式；图集已附入 [runtime/v1](../../runtime/v1/README.md)。周期与实际显示问题可在接入时针对调整。
