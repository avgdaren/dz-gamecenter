## 视觉与摆放

共用奶油白、浅金边与海蓝门窗，保留现有轻幻想插画风格。贝壳小屋是低宽粉色屋顶，风车由薄荷绿四叶片形成剪影，钟楼用紫蓝尖顶和星形钟区分，船馆采用低横木船壳与粉色遮篷。背景“暖潮浅湾”使用左上暖光、低矮两侧珊瑚与开阔沙地，未烘焙鱼或可购买建筑。

四件合成建议为 2 后景＋2 前景，沿用当前每层最多 3 件。后景风车 x=.12／钟楼 x=.89、地面 y=.80；前景小屋 x=.34／船馆 x=.66、地面 y=.91。可见宽比例为 .12／.095／.21／.27。位置与大小都是美术评审建议；预览用测得的主体边界与锚点计算，而不是依赖原 PNG 透明留白。

合成确认了一个后续接入问题：当前 1.2.2 的同层自动排布会把两个后景和两个前景都放在约 1/4、3/4 位置，让钟楼与船馆等前后叠成一栋。预览保留“1.2.2 自动排布”对照，并默认展示独立错位的推荐构图。**推荐点位尚未实现到游戏中**，不能把推荐截图当作已接入效果；接入时须处理层间关系与左右换序。

## 质量检查及边界

- 通过：五张选用 PNG 解码、尺寸与模式检查；四张建筑 alpha 为 0–255，背景全不透明；选用文件与图像工具输出逐字节一致、SHA256 全部匹配。三张参考初稿另存，哈希可追溯。
- 通过：manifest／提示词／预览嵌入 JSON 一致，原生预览 JS 语法及所有本地链接／素材路径检查。
- 通过：桌面 1280px、移动 360px（页面 scrollWidth 345px）加载无缺图、无横向溢出。推荐构图四建筑可见 bbox 无相互重叠；切换现行排布可复现前后层同横坐标的叠放关系。
- 通过：暖潮／日光／月光切换、3／12 鱼数量、建筑显隐、深浅底与 64／128px 缩略示意控件。尺寸切换时曾发现短暂零尺寸导致的几何错误，已加保护与背景加载后重排；干净标签完整复核后无 error/warn。
- 截图保存于本机评审目录，不把浏览器日志或任何玩家存档提交入库。静态参考鱼不是实际游动／遮挡测试；夜景切换的加载检查不等于新素材的运行时调色验收。

母图放大后仍可见少量边缘杂色，未将“一轮图像工具清理”标成最终抠图验收。alpha≥16 的主体连通域之外，小屋／钟楼／船馆为 0 像素，风车为 1 像素；这只用于排查明显游离碎片，不能证明半透明轮廓没有彩边。原始 alpha bbox 与主体 bbox 均保留在 manifest。

PNG 是工具的原始尺寸，尚未规范化为 1024px 母版、512px 或 1024×512 WebP、128px 商品图。部分图留白较紧，原始脚点也不是统一的 (0.5,.9)。64／128px 仅为浏览器缩略示意。背景 1586×992 接近16:10，预览只通过 object-fit cover 显示，没有改原图；正式桌面／手机导出尚未做。

未验证：主人最终美术认可、正式缩略图清晰度与边缘、游戏内夜景调色、动画（本轮建筑先做静态）、新商品／新配置／持有与装备链路、论坛加载和手机实机性能。浏览器合成不是下一版实机验收。
