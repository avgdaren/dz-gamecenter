# 天使水族馆：鱼与场景差异化制作要求

作者：GPT / Codex；原插件 (C) 2026 Carinoasd。2026-10-29（北京时间）。Refs #22 / #29 / PR #31。

用户本轮已认可晴蓝鱼、羽鳍鱼、日光场景；同时要求后续批量有不同风格的鱼和场景，装饰先给样稿。认可范围是三张样张的视觉方向，不自动等于导出规格、装饰、展示位或价格获批。

## 鱼：统一二次元美术，拉开造型与气质

不把晴蓝鱼复制12次换颜色，也不把所有珍奇鱼都做成同一套白色长羽鳍。下表是既有12个ID的造型计划，不修改鱼种数、权重、金币、保底或获取条件；未出图项不是用户已认可素材。

| ID | 中文名 | 主要轮廓 / 气质 | 批量检查重点 |
|---|---|---|---|
| pond_blue | 晴蓝鱼 | 圆润短身、短鳍、蓝青色，亲近活泼 | 已认可样张；保留大色块和清晰面部 |
| pond_orange_tail | 橘尾鱼 | 略长的短身、展开的扇尾，橘白暖色 | 尾形与晴蓝鱼不同，不画成蓝鱼换橙色 |
| pond_leaf | 叶纹鱼 | 细长叶片形、窄尾，青绿自然感 | 全身长宽比和游姿不同，叶纹不堆细线 |
| pond_peach | 桃心鱼 | 短小高背、心形尾轮廓，桃粉柔和 | 以整体轮廓而非贴一个爱心区分 |
| pond_glass_moon | 玻璃月鱼 | 扁圆薄身、通透鳍，银蓝月影 | 透明感由有限色层表现，缩小后不能消失 |
| pond_feather | 羽鳍鱼 | 白金短体、羽片长鳍，优雅轻盈 | 已认可样张；长鳍仍须保留鱼体辨识 |
| bay_silver | 银沙鱼 | 流线梭形、分叉尾，银灰冷光 | 速度感和中性配色，避免又一条大眼圆球 |
| bay_coral | 珊瑚鱼 | 短高体、较明显的背鳍，珊瑚红 | 与橘尾鱼区分体形及鳍，不只换红色 |
| bay_lantern | 灯笼鱼 | 泪滴形体、圆腹，温暖微光 | 一项发光特征即可，不叠羽翼/星斑 |
| bay_ribbon | 丝带鱼 | 细长体、飘带鳍，蓝紫柔美 | 保留大段顺滑曲线，不画成羽鳍分叉 |
| bay_star_ray | 星斑鳐 | 扁平菱形盘体、长细尾，深蓝星斑 | 鳐的独立剪影最强，不套普通侧身鱼模板 |
| bay_aurora | 极光天使鱼 | 高耸三角鳍、纵向舒展，极光青紫 | 与白金羽鳍鱼区分高宽比和尾形，不再重复羽毛 |

审看时同时比较轮廓、身体长宽比、鳍尾、配色/明暗、主要幻想特征；至少在前三项中看到差异。每条只保留一个主要幻想特征，品级不等于堆叠装饰。编号/中文名/文件映射保持显式，不因造型重做改fish_id。

## 场景：换主题与远景轮廓，不只调色

已认可日光样张；后续场景按下列方向出差异稿，再依据实际内容清单确定批量数量。当前registry仍只列日光/月光两个背景目标，珊瑚/遗迹为后续场景方向，未自动加成四个首发背景，也不新增钓点或付费商品。

| 方向 | 与日光的实际差异 | 共同要求 |
|---|---|---|
| 日光自然 | 晴砂、开阔水体、温柔日光，明亮易亲近 | 当前样张已认可，中心可布置 |
| 月光庭院 | 冷色静水、庭院远景、圆弧剪影、局部暖光 | 重做夜间层次和远景，不把日光整体染蓝 |
| 珊瑚浅湾 | 暖浅水色、扇状珊瑚/礁体远景、明快热带感 | 与绿色水草/石柱景不同，不烘焙可购买珊瑚物件 |
| 幽蓝遗迹 | 纵深更强、断柱与残拱剪影、深蓝神秘感 | 不做昏暗恐怖风，鱼脸与小尺寸仍清楚 |

原“日光/月光同构图”细化为**共用视角、画布/地面基准和可布置安全区**；主题轮廓与植被/光照可以变化，不要求复制整张日光底图。日光已通过不代表后续场景自动通过，下一主题先看差异稿。

## 装饰：先样稿，后批量

本轮先交晴光水草、绮色珊瑚、月庭圆门、星辉提灯，四类各一件，见[装饰样稿](DECOR-SAMPLES-v0.1.md)。自然填充/珊瑚造景/建筑主景/金属灯饰应有明显的轮廓和精细度差别，仍能放在同一鱼缸中。

装饰样稿未经用户审看不进入24件批量；样稿原图尺寸相同不代表实际摆放一样大。水草/石景低价、建筑最高价、摆件按可见精细度分档仍为定价原则，不根据本轮生图次数改变价格。
