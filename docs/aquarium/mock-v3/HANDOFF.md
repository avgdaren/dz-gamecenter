# 水族馆 V3 交互样稿 · 交接说明

作者：小蓝（DSH）· 2026-10-29 · 依据 Issue #36 讨论结论

## 一句话

这是一个**独立 HTML 样稿**，用来定玩家界面的交互模型（鱼缸比例、装饰摆放、自由游动、直接放入、自动保存）。它不改插件代码、不碰存档，验证通过后再落进 `games/aquarium/game.js`。

## 怎么跑

```
把 index.html 放到站点任意可访问目录，例如 E:\dzx5-env\www\_mock\aquarium\index.html
浏览器打开 http://localhost/_mock/aquarium/index.html
```

资源走 `/source/plugin/gamecenter/games/aquarium/assets/`，所以必须在站点根目录下访问，不能双击 `file://` 打开。

## 已定结论

| 项 | 结论 | 来源 |
|---|---|---|
| 鱼缸比例 | **16:10** | 用户实机对比 4:3 后定 |
| 宽件占格 | **占 2 格成立**，但只影响视觉排布，不改容量语义 | 用户确认；容量仍按件数（每层 3 件） |
| 装饰尺寸 | 按类别给系数：水草 0.60 / 摆件 0.70 / 石景 0.80 / 建筑 1.00 | 用户反馈「水草太大」 |
| 前后景锚点 | 后景居中 25/50/75；前景从右起 72/28/50 | 修「灯压在桥中间」 |
| 放入方式 | 卡片点一下直接进缸，再点收起；**不跳页、不点保存** | 用户反馈第 2 条 |
| 自动保存 | 串行队列，逐条标「排队 / 保存中 / 重试 / 已保存」 | GPT 第 5 点 |
| 手机 | 先不做专用规则，等有人反馈再改 | 用户判断（论坛主要 PC 用户） |

## 实现要点（落进游戏时照这个来）

1. **增量更新，不重建**：每次操作只创建/移除受影响的那个元素。整层重建会让所有鱼瞬移、图片闪烁，用户会当成 bug。
2. **归一化坐标**：鱼的位置存 0~1，渲染时乘容器尺寸。切比例、改窗口宽度都不跳位。
3. **入场动画**：鱼从下方 26px 缓动浮上来 + 0.72→1 放大 + 一圈涟漪；装饰从上方落下带回弹；收起统一「下沉 + 缩小 + 淡出」0.3 秒。
4. **游动**：`requestAnimationFrame` 驱动，每条鱼 `{angle, target, speed, cruise, pause, flip, tilt}`；限速转向 1.6 rad/s、速度缓变、碰边按墙面镜像反射、翻转带迟滞（|cos| > 0.22 才翻）、身体随上下速度倾斜 ±9°。
5. **保存队列**：操作入队 → 逐条提交 → 版本冲突时拉最新再重试一次 → 逐条标状态。不做「一失败全回滚」。
6. **点选高亮**：切换选中态只改 class，不重建 DOM。

## 已验证

- 加鱼 / 加装饰后，原有元素仍是原 DOM（用标记法验证，没有重建）
- 连续快速点 3 件装饰，4 次操作全部入队并标记「已保存」，无丢操作
- 16:10 / 4:3 / 390px 三档都不溢出，无 JS 报错

## 未验证 / 待定

- 12 条鱼 + 6 件装饰同时在场时的拥挤程度（样稿只放了 4 条鱼）
- 手机端装饰收敛规则（用户暂缓）
- 「宽件占 2 格」是否真的要改容量语义（涉及 `decor_slots_per_layer`、服务端校验、存档结构），本轮不做
- 游动仍是单帧贴图 + 旋转/翻转，没有游动帧；要更自然需要美术再出 2~3 帧
