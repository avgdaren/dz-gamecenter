## 公告使用

- 标题：**天使水族馆 v2.0 更新｜萤光秘境，新伙伴来访**。
- [Markdown 公告](announcement.md)：含相对路径头图，可在仓库直接预览。
- [Discuz BBCode 正文](announcement.bbcode.txt)：正文没有图片附件 ID 或时间占位符。先上传 800×450 头图并放到帖首，再粘贴此正文；按论坛实际附件 ID 插图，不使用私有仓库 raw 链接充当图床。
- 宣传统一称 v2.0 大版本；本次只读核对的本机配置版本为 2.0.9，最终发布包构建号由小蓝确认。本目录不改变游戏版本号或运行配置。

本轮没有代发论坛帖子、创建 GitHub Release、合并 PR 或部署。公告没有写“已正式上线”、具体开服时间、“唯一夜景”或可随时退回旧版。实际发布时，先确认发布包已部署且开放项与正文一致，再发帖。

## 已核对的公告事实

本轮只读核对本机 game.json、content-v3-candidate.json、背景目录、aquarium_configs.php、aquarium_shop.php 与相关 UI。它们不是远端 feat/aquarium-v2 分支已包含的运行代码，也不是本轮重新完成的一次功能验收。

- 三种新生物：海龟/蝶鱼为浅湾珍奇，古比为池塘稀有；门槛 Lv.5，终身各 6 条。
- 竿数组最后一项 20,000 金币 / 60,000ms；14 件 firefly 布景合计 90,000，秘境背景 10,000。
- 背景目录含七景；已拥有记录与切换校验已在本机代码中出现。主题包按缺件分别购买，不把它宣传成整套原子交易或额外打折。
- 本机 limitedSellable 白名单明确包含三个新生物；服务端与图鉴投影都使用此白名单，售卖开关为 all。因此交接里“限量鱼仍禁售”改为“原四种限量生物继续禁售”，不把新三种也排除。
- 售鱼保留至少 4 条及展示占用；出售不回退终身捕获数。
