## 1. 版本定位

v2.0 定位为「新生物、主题布景与售卖系统」大版本：通过新增生物扩充收藏，通过“萤光秘境”形成完整主题布置，并打通鱼类出售、主题商品购买和自由搭配的使用流程。

卷尾海马、铃伞水母、软糖章鱼、月汐人鱼已经更新，属于现有内容，不计入 v2.0 新增名单。

本轮下版美术范围已选定：青芽海龟、绮霞古比、珊澜蝶鱼三种生物，萤光秘境背景、14 件布景素材与四组预设。三种生物的当前静态造型按主人反馈保留，名称按最新会话登记；旧蓝色古比、金黄/莓紫蝶鱼与花鳃小龙均不纳入当前选用目录，团团河豚仍作未制作的备用方向。

统一交付入口：[下版美术选用包](../art/v2-release-selection/README.md) · [机器清单](../art/v2-release-selection/manifest.json) · [接入交接](../art/v2-release-selection/HANDOFF.md)。本包共 18 张静态 PNG 母图，三种生物的动画与运行导出仍待完成。

## 3. 新生物细表

2026-11-08 定稿记录：当前选用青芽海龟、绮霞古比、珊澜蝶鱼三张静态母图。旧小龙、蓝色古比及金黄/莓紫蝶鱼仅作历史留存，不再列为当前接入目标。

| 生物 | 外形与配色 | 游动辨识点 | 首发建议 |
| --- | --- | --- | --- |
| 青芽海龟 | 翡翠绿背甲、奶白腹部、四片宽鳍肢；略俯视侧身 | 鳍肢交替划动，身体缓缓滑行 | 造型已认可，待制作动画 |
| 团团河豚 | 接近圆球的身体、短尾、小鳍、少量圆钝短刺；奶黄与淡褐 | 小鳍快速划动，身体轻轻起伏 | 保留为替换候选，注意与现有灯笼鱼拉开轮廓差异 |
| 绮霞古比 | 杏金鱼身、霞粉大扇尾、莓红眼睛、小金冠；更纤巧的右向侧身 | 大扇尾低幅摆动、胸鳍轻划；皇冠随头部稳定运动 | 当前选用暖色母图，旧工作名仅保留历史 |
| 珊澜蝶鱼 | 暖白短高鱼身、珊瑚橙背鳍、青色眼后弧纹与一小簇暖色花斑，小尾与连贯背腹鳍 | 平稳巡游、胸鳍轻划、小尾摆动 | 当前选用花纹重设计 v03；金黄和莓紫版均退出 |

每种入选生物的交付范围：

- 完整造型母图与透明运行素材。
- 游动循环及对应的朝向、体型和运动参数。
- 图鉴图标与未发现剪影。
- 名称、简介、水域、捕获条件和库存展示。
- 放入、收起及与现有投喂表现的衔接；是否参与追食按物种表现单独确定。

获取方式建议延续现有钓鱼与图鉴体系。所属水域、鱼竿门槛、捕获权重、是否终身限量及限量数值均待定，不直接套用此前四种生物的规则。动画帧数和素材尺寸在制作规格中确定，本方案不先固定数值。

四组存在成员复用，合起来覆盖 14 件；不是合计新增 21 件素材。

布置规则沿用已有方案：

- 预设免费，单件素材独立拥有，可单件替换、自由调整和跨主题混搭。
- 使用前显示组成、已拥有项和缺少项；应用仅使用已拥有内容，缺件提示并跳过。
- 缺少主景时提示应用后为简化布景；全部装饰均缺失时保留当前布景。
- 未拥有主题背景时保留当前背景并提示。
- 应用预设不会自动购买、发放物品或扣金币。
- 本期按前后两层、每层最多 3 件规划。14 件是可选目录，不提高为同时摆放 14 件。

## 6. 鱼类售卖系统

本版目标是让玩家能看清可售库存、选择数量、确认金币收益并完成出售。

| 功能 | 规划内容 | 规则状态 |
| --- | --- | --- |
| 可售范围 | 普通鱼可售；现有终身限量生物沿用不可售规则 | 沿用既有方向；新增生物的可售资格随限量规则确定 |
| 库存信息 | 分别显示持有、展示和可售数量 | 本版必备 |
| 可售数量 | 根据真实持有、展示占用和保留规则计算 | 建议首发排除正在展示的鱼；保留数量待定 |
| 售卖入口 | 从鱼类库存或图鉴关联入口进入 | 具体入口随界面布局确定 |
| 数量选择 | 选择单个鱼种及出售数量，显示单价与预计所得金币 | 建议首发采用手动按鱼种出售 |
| 确认出售 | 确认鱼种、数量和总收益后成交 | 本版必备 |
| 成交结果 | 更新金币、持有数量及可售数量，显示本次结果 | 本版必备 |
| 重复操作处理 | 连点、刷新或重复请求不重复扣鱼、发币 | 本版必备 |
| 图鉴保留 | 出售不清除已发现记录，也不重置终身捕获计数 | 本版必备 |
| 全局控制 | 保留独立的售卖开放/关闭能力 | 具体开放安排待定 |

首发建议不加入自动售鱼与跨鱼种一键清仓，以手动、可预览的单鱼种出售流程为主。

## 7. 主题商店、套装与经济规则

| 项目 | 规划内容 |
| --- | --- |
| 单件购买 | 背景、建筑、景观和普通装饰分别展示与购买 |
| 商品展示 | 提供名称、预览、价格、解锁条件和已拥有状态 |
| 主题套装 | 建议以“萤光秘境背景＋14 件场景素材”为完整主题商品范围 |
| 缺件补齐 | 已拥有的成员不重复购买，只对缺少项报价；购买前列明缺件与总价 |
| 独立拥有 | 套装购买后，各成员仍为独立物品，可与其他主题混搭 |
| 预设关系 | 四组预设是免费推荐摆法，不额外作为四份付费商品 |
| 属性边界 | 主题商品提供外观与搭配，不增加钓鱼产出或捕获概率 |
| 成交反馈 | 扣款、获得物品与拥有状态同步更新，已拥有物品不重复扣款 |

需统一确定的经济参数：普通鱼售卖单价、库存保留规则、原有捕获收益与售鱼收益的关系、主题单品价格、套装折扣、补齐计算方式及解锁门槛。

此前 25,000/20,000 的旧候选报价不适用于新的 14 件目录。本稿不把旧报价、旧折扣或单买差价处理方式当作已定规则。

| 商店 | 主题入口、单品目录、套装组成、缺件补齐、价格与拥有状态 |
| 布置 | 四组预设、组成预览、缺件提示、应用及自由调整 |

旧版本升级时保留金币、鱼类持有、发现记录、终身捕获计数、鱼竿与水域进度、已拥有背景和装饰、现有布置及历史成交结果。新内容加入目录后，不重置旧进度、不重复赠送旧物品。

升级本身不自动把玩家当前布景切成新主题，不自动购买套装，也不自动出售库存。

## 9. 后续推进顺序

以下为后续工作安排；本次先完成独立分支、规划入库和执行交接，功能与美术制作随后分批推进。

| 阶段 | 工作范围 | 形成的产物 |
| --- | --- | --- |
