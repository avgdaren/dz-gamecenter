# 天使水族馆 · 第一版声音资源与小蓝接入说明

作者：GPT / Codex；原插件 (C) 2026 Carinoasd。日期：2026-10-30。关联 Issue #40。

## 交付与听感目标

第一版原创合成音色候选。温暖、轻盈、略带童话感，陪伴看鱼；没有人声、强鼓点或高频常响的铃铛。合成键音不是实录钢琴，本批也没有使用《怪怪水族馆》的音频、外部采样或第三方音源。

| ID | 内容 | 长度 | 使用 |
| --- | --- | --- | --- |
| bgm_sunlit_fish | 《晴光里的小鱼》；键音、拨弦、木琴、薄铺底；D 大调，80 BPM，48 小节，六段变化 | 144 秒 | 日间／默认主曲，循环 |
| sfx_place | 小气泡与柔和木音 | 约 0.48 秒 | 放鱼、放装饰；一次操作只响一次 |
| sfx_select | 短促柔和的气泡点选 | 约 0.16 秒 | 有意义的选中动作，节流至少 120 毫秒 |
| sfx_success | 三音上行木音 | 约 0.95 秒 | 服务端确认购买或升级成功 |

运行资源位于 `source/plugin/gamecenter/games/aquarium/assets/audio/v1/`。独立 audio manifest 不改美术 manifest。每件资源有 OGG 与 MP3 两种格式，二者是备选，不同时加载。OGG 主曲 801,638 bytes；运行资源八个音频总计约 2.57 MB，实际首载优先选 OGG 组合约 0.82 MB。

## 试听

完整解压后直接打开同目录 `preview.html`；也可以在本地测试站保留仓库目录结构访问。试听页的路径是相对路径，不连接账号，不改变存档。浏览器若限制本地媒体加载，改从本地站点访问。

- `preview-24s.mp3`：主曲前 24 秒，便于快速判断风格。
- `sfx-audition.mp3`：依次为放入、点选、成功，中间有停顿。
- 完整主曲可从运行目录直接播放。试听页有“结尾接回开头”按钮，检查实际浏览器循环体验。

## 小蓝接入约定

1. 用户首次进入时音乐与音效都关闭，明确点击“开启声音”后启用；两者分别控制，建议音乐 gain 0.35、音效 0.50，记住当前浏览器内的用户选择。试听页默认音量不代表游戏自动启声。
2. 先完成用户手势内的音频解锁，再异步加载；不阻塞鱼缸或存档读取。不支持格式、音频加载失败或播放被拒绝时，游戏继续可用，保留静音状态并允许手动重试。
3. BGM 保持一个实例，打开图鉴、购买、放入物品都不从头播放。进入／退出用约 0.6～1 秒渐变，避免硬切。页面隐藏时暂停／挂起，返回前台按先前设置恢复，不能因此把关闭的声音打开。
4. 多标签页约定单一声音播放页，或至少提供明确的切换机制，避免几份 BGM 同时响。保存冲突、断线重试不播放成功音。
5. 自动捕获和离线结算中的每条鱼不逐条响。放入已经播放 place 时，不再叠加 select；success 只在服务端确认后播放，幂等响应与重试不得重复触发。同一帧批量布置最多响一次 place。
6. 本曲是周期渲染：尾部余响回卷至开头，OGG 为推荐循环源。可用 AudioBuffer 循环；若用 HTMLAudio.loop，须在目标浏览器实际验收边界。MP3 的编码延迟处理与解码器有关，备用格式也要验，不能仅凭文件时长宣称所有浏览器无缝。
7. 主曲与音效使用独立增益、限制音效并发（建议最多 3 个），音量调零即静音。声音状态不进入金币／布置存档，不改数据库、后端接口或插件版本。
8. 先把试听候选接到测试页面。实机确认后再决定正式默认资源；夜间音乐本批未制作，不要把同一曲改名当第二首。

本批只增加资源、试听与制作源码，没有修改 game.js、存档、插件设置、线上站点或小蓝的交互分支。

## 已验证与尚未验证

- PASS：八个运行音频均可用 FFmpeg 解码；44.1 kHz、双声道；时长正确；样本有限；无削波；峰值留有余量；文件 SHA-256 与 Git blob SHA 可核对。
- PASS：OGG／MP3 主曲解码后均为 144 秒；OGG 边界样本跳变约 0.00131，低于边界附近普通相邻采样变化的第 99 百分位（约 0.01745）。这是信号检查，不等同于浏览器听感验收。
- PASS：FFmpeg EBU R128 检查，OGG 主曲约 -20.5 LUFS、动态范围约 6 LU、true peak 约 -7.4 dBFS。未做商业母带或实录音色承诺。
- PASS：制作 Python、试听页 JS、JSON 与相对资源引用检查；详见 QA.json 和 CHECKS.json。
- 未验证：用户主观听感；连续十分钟是否耐听；真实浏览器解码／循环；手机与 Safari；游戏内音量平衡、用户手势、后台恢复、多标签页和错误状态。无实站 PASS 声明。

## 可复现与修改

离线制作需要 Python 3、numpy、scipy、ffmpeg。它们仅用于制作，不是线上依赖，不引入 npm 或 CDN。

```sh
python3 tools/render_aquarium_audio.py --out /absolute/path/to/output
```

固定随机种子 20261030；编曲事件见 `score.json`，包含拍位、音高、音色、力度与声像。脚本输出 PCM WAV 母版、两种运行格式、试听片段和 QA。WAV 母版不放运行目录，避免部署时额外下载几十 MB。相同工具版本可复现；不同 FFmpeg 版本的压缩字节和哈希可能不同。

后续调整优先改主旋律密度、木音比例、混响长度与整体明亮度；先听这一版再决定是否换音色或重编曲。
