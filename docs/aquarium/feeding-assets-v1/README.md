## 美术接入

1. 用单图替换 `.aq-food` 的CSS占位径向渐变。移除原来的背景颜色与强发光，保留透明外边，禁止给图像叠米黄色圆底，否则会重新像金币/光点。不要放大成截图中一团金色亮点。
2. 正常场景保持原色；月光场景可轻降亮度/高光，先原图实景检查。不要把夜景颗粒提亮成白点。
3. 每次最多6粒，重投清上一场；每粒有唯一id与本场generation。鱼实际吃到这一粒后才启动120–180ms的scale+opacity退出，并删除节点。不能用鱼抵达同一个中心位置作为“吃到”。
4. 像素图内部有约10%透明留白；食物实际可见直径略小于CSS盒子。生产小尺寸请选32px导出，不直接下载1254px母版。使用背景图集时，背景尺寸跟随CSS显示尺寸缩放，避免只截到图集边角。
5. 原先#53的独立停留位、鱼体间距、可达筛选、边角降级和最多4响应仍要实现；**换美术不会修复聚团**。

## 音效接入

- **触发点：** 本地某粒食物从available变成consumed，并且本次generation有效、被认领者仍存在。先原子标记一次，再触发播放与消失；同一颗不能在多帧/多鱼之间重复响。
- 不是点击撒粮时响，也不是鱼刚靠近就循环响；售卖“叮”、现有金币音与本音效分开。
- 三变体轮换或随机但避免连续同一条。建议初始volume=0.45，峰值母版约-12dBFS；实站与轻快BGM混听后再调。不做每次normalize到0dB的处理。
- 全场共享140ms最短触发间隔，最多2个同时发声；超限就跳过这次声音，不补播积压队列，粒子消耗照常。不要覆盖原有声音管理器的全局限制。
- 复用现有“音效”开关。静音、后台、减少动态结束场次、离开页面或重投时取消本场正在播放/待触发声音；新场使用新generation。已确认结束的老Audio实例需释放引用。
- 按浏览器自动播放规则在用户交互后解锁，play失败静默处理，不延迟补响。断网时已缓存资源可播，缺失则静默，不能因此影响库存或动画。
- 音量与资源加载是前端状态；没有音频服务端API、不写存档、不发币。
