1. **覆盖文件。** 将候选的 `source/plugin/gamecenter/` 覆盖到测试站同目录，保留目标现有文件。不导入新版插件定义，不改 `common_plugin.version`，不调用安装/升级入口。
2. **手工建唯一新表。** 在测试站数据库运行 `source/plugin/gamecenter/aquarium-install.sql`。内容只有 `CREATE TABLE IF NOT EXISTS pre_gamecenter_aquarium_save (...) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;`，没有DROP、ALTER或写旧表语句。执行后用SHOW CREATE TABLE核对表前缀、InnoDB、主键uid及全部列与 `lib/aquarium_schema.php` 一致。重复执行不删数据；若已存在同名但结构不同的表，IF NOT EXISTS不会修复，须停下核对，不能当成已兼容。

缺表时服务会报暂不可用；缺注册记录时入口会报游戏不存在。不要为消除报错而卸载重装或清档。诊断页只有底盘占位内容，不是已批准概念图的正式画面。
