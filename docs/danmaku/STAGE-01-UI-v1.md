## 这次的界面

- 桌面改为战场＋右侧状态栏。完整关卡是默认入口，专项练习收进“关卡与练习”；声音设置、操作提示和回放工具按需展开。
- 放大并突出战场、分数、生命、大招和火力。新增火力进度条，道中进度与Boss生命用不同颜色及文字标注；剩余时间、登场、转场与结算总用时分别标明。
- 保留原少女正面图，桌面位于右侧，窄屏位于战场下方；没有把角色图覆盖到弹幕区。
- 窄屏把生命、大招、分数和火力移到战场上方，按钮保持至少44px高。低矮小屏单独缩放战场，保持3:4比例并让主要操作按钮处于首屏。
- 开局、准备声音、暂停、恢复倒计时与结算使用同一套界面。结算集中显示分数、用时、阶段突破和擦弹；计分明细可折叠，保存回放与再次挑战并列为明确操作。
- 查看关卡设置、操作提示、回放工具或声音设置会主动暂停；恢复仍走原倒计时。声音音量与开关沿用原有本机存储。

运行文件仅改动 `index.html`、`style.css`、`ui.js`。Canvas仍为480×640，模拟时钟、输入映射和追帧保护沿用旧实现。没有引入npm、第三方CDN、网页字体、外部运行服务或新构建依赖。
