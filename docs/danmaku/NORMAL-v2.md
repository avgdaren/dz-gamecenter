## 全局掉命规则

每次受击扣掉一条命、且仍有剩余生命可复活时，大招／练习清屏库存**赋值回该模式开局数量**：标准2枚，辅助3枚。0枚或1枚会补回，标准攒到3枚也会回到2枚。完整关卡的道中／全部Boss阶段、两档首领练习和三种基础弹型练习统一生效。

无敌期间没有掉命就不重置；同帧多弹只扣一命、重置一次；同帧已成功开B则按原先清弹／无敌顺序处理，不额外掉命／补B；最后一条命结束不再补发。库存重置不冒充B拾取，不增加拾取／溢出分或已用大招计数；阶段转场也不额外补发。原强化掉落、受击清弹和无敌时长保留。

为保留历史回放，当前新开局版本为：

| 模式 | 当前规则 |
|---|---|
| Easy完整关卡 | `danmaku-stage01-r4` |
| Normal完整关卡 | `danmaku-stage01-normal-r2` |
| Easy／Normal首领练习 | `danmaku-p1-r4`／`danmaku-p1-normal-r2` |
| 三种基础弹型练习 | `danmaku-p0-r3` |

旧 r1／r2／r3／Normal v1 仍按原版本复验，不用新补B规则重解释旧记录。`rules.json` 仅追加 `normal02`，旧配置值和 `normal01` 不变；Normal v2 的道中类型直接继承 Normal v1。新开局的全局规则不是只对 Normal 生效。
