## 1. 美术以第一关实际画面为参照

- 统一角色的像素尺度、描边方式、阴影层次、边缘质感与同屏体量。新关卡的主题配色可以变化，不要求所有角色共用第一关的蓝色或同一张色表。
- 小怪对照第一关同类小怪，Boss对照第一关Boss；分别保持合适的头身比例与细节密度。第一关小怪可以有Q版比例，不据此把修长Boss也改成大头、粗轮廓的另一种画法。
- 参考实际可见轮廓及其与自机、弹幕的大小关系，不能只对齐画布宽高，或用放大人物／放大头部代替小尺寸设计。
- 新关卡可变的是衣装、发色、武器、花叶与场景装饰等主题内容；人物身份和已确认大立绘继续作为约束。需要提高辨识度时，先在既有画法内整理轮廓和信息密度。
- 新素材提示词必须同时引用本关人设与第一关同类运行素材作为身份／风格参照，不能只引用本关独立概念图并泛写“像素风”。具体生成和像素处理方式仍遵守当次工具、用户及仓库要求，不因本契约自动取得额外处理授权。

主要参照：[第一关小怪素材](STAGE-01-ART-PRODUCTION-v1.md)、[第一关Boss素材](STAGE-01-BOSS-ART-v1.md)，以及当前运行目录 `_danmaku_proto/assets/`。生产记录中的早期动作方案不替代当前已认可的实际运行效果。

## 2. 演出共用结构与反馈语言

- 全作共用Boss名牌布局、字号层级、立绘进退方式、阶段提示、击破／清弹反馈和收尾节拍。实现上优先复用共用组件与主题配置，避免每关另做一套界面和镜头语言。
- 允许按关卡替换装饰形状、局部配色、音色、角色动作与发射源：第一关可用星仪，花庭可用风纹、花瓣和铃声，但它们应依附同一种演出结构。
- 阶段转换要让玩家以熟悉的方式识别“本式结束／下一式开始”。实战中保持共同的危险信息层级，演出不盖住通路、自机判定点或必要读数。
- 共用结构不等于所有关卡强制相同时长。已确认的停顿、移动和音乐安排作为关卡参数保留；不得仅为新演出自行增加等待时间或改动攻击时序。

主要参照：[第一关演出](STAGE-01-SHOW-v1.md)、当前 `stage-show.js`、`ui.js` 与 `style.css`。先对照当前第一关的实际登场／换阶段／击破效果，再扩展主题表现。

## 3. 道中按完整波次组织，音乐配合关卡

- 先设计引入、编队推进、组合变化、压力高潮、拾取空隙和收束，再对齐音乐乐句；整首BGM时长不能直接决定道中必须持续多久。
- 敌人以有起止、队形、职责和明确应对方式的波次出现。音乐拍点用于协调波次内的出场与发射，不能成为长期按固定间隔零散刷单个敌人的主要编排方式。
- 重复用于引导和检验同一种应对方式，后续通过方向、队形、配合或攻击组合产生变化；不以重复相同路线和攻击填满音乐。
- 保持第一关“成组进入 → 判断／击破 → 收集 → 短暂喘息 → 下一组”的体验。关卡可以逐渐发展规模与变化，长度、空档和补给应有实际作用。
- 这种收放结构不要求沿用第一关的敌人数、单位时间出敌量、队形、路线、出场间隔或攻击组合。后关应依据主题、地形／场景和玩家继承火力独立编排；可增加成组目标、同时存在的职责组合与压制段，让成长后的散射、集中和清场能力有实际用途。
- 场景滚动速度与关长分开设计。已确认的前进速度不代替出敌节奏，也不能用加快背景来掩盖波次编排问题。

基线：[第一关关卡设计](STAGE-01-DESIGN-v1.md)及当前Easy／Normal的实际编排。第一关基础道中为72秒，这是对照，不是全作所有关卡的固定上限。

## 4. 同档规则一致，战斗按继承资源递进

- 比较相同难度档，并记录进入关卡时的实际生命、火力、B与其他继承状态。独立练习的满资源配置不能代替连续游玩的判断。
- 后一关同档可以比前一关稍难；编队规模、密度、方向、攻击类型、弹幕几何与应对方式按本关需要变化，Boss可有独立招数和阶段结构。共同的是读懂危险、合理反应、击破和恢复的体验，不要求原样复用第一关招数、弹速或每种预警的具体时长。
- 后关的主要压力以玩家实际从前关带来的成长状态设计。同资源对照只用于分析差异，不能替代“第一关起始资源 → 第一关结束资源 → 第二关压力”的连续关系。检查正常成长、有损耗和低火力恢复等代表性状态，不把当前练习预设当作已验证的真实抵达资源。
- 敌人数、出敌速率、弹量／峰值和HP与第一关相同或更低，都不是一致性或Easy合格标准。高火力下敌人是否出手前就被成片清掉、组合压力是否还成立、阶段是否过早结束，比单独对齐数量更有解释力。
- 不以道中拖长、重复增加或敌人血量膨胀代替难度设计。HP可以按角色职责、实际火力和目标战斗时长独立调整；不强制与第一关相同，也不机械按火力等比例加血抵消成长收益。保留高火力清杂与快速处理重点目标的回报，同时给低火力恢复留出可行空间，不能将整个后关按低火力状态降平。
- 自机操作、命中判定、集中射击、成长、死亡恢复、大招等通用规则保持一致。关卡特殊机制需要明确设计和说明，不能在独立草稿里悄悄改成另一套基础玩法。
- “沿用了Easy规则底座”不等于“已完成Easy标定”；只有一套独立攻击草稿时如实注明，不能直接当成Easy／Normal／Hard已齐备。

## 5. 跨关卡对照作为制作过程的一部分

在扩展整套动作、特效和完整流程之前，先交第一关与新关卡的实际尺寸同屏角色对照，以及共用演出结构的短样。角色先确定标准战斗姿态，再扩展移动与施法；对照中同时检查辨识度和全作风格。

关卡编排先做紧凑、能体现起伏的一段，再扩为道中；按相同难度及有代表性的抵达资源检查。用户确认方向后继续扩展，不把单张独立美图的认可扩大为整关、全部动作或难度已验收。
