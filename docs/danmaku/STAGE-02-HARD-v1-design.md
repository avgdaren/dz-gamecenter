## 道中

以当前第二关的96秒／8秒首敌与完整编队为基础，保留既有补给和24–27、44–48、57–60秒附近的整备空隙。将成对司铃的右侧出手错开36步，两名守卫分别占左／右岸；17.4／18秒与68.2／68.8秒补三路侧入，37.2秒补两拍齐列，76秒增加错拍司铃组合。总计140敌，新增目标不另塞奖励。

轻型有效命中即破；中型208HP、守卫600HP。首发分别出生后78／84／108步，发射前36步显示现有预警；轻型侧入仅用第一轮锁定，直列保留后续展开。两关共用自机、成长、掉命补B、移动、碰撞、吸附与大招规则不变。

## 铃羽三式

| 阶段 | 结构 | 压力与空隙 |

| 风廊 · 回卷双风 | 双源叶／花流束逐拍扫入，96步后偏转并反向弯曲；每句末以两圈收束 | 要同时读首波与回卷到达次序，收句缺口按乐句迁移；不用固定墙填屏 |

| 铃声回响 · 三铃错奏 | 一铃主鸣、另两铃错拍回答，每句以三铃和弦收束，末两拍留白 | 主鸣与慢回声相遇，预先换位；三铃收句向共同通路留缺口 |

Boss HP为6300／6900／7500。沿用既有冻结Boss拍点与跨阶段音乐时钟，单式开始前36步不出弹；音乐390–12960步范围内按有效拍点发射，不在渲染帧或音频回调生成弹幕。所有运动状态使用既有整数运动数组和32px新弹出生保护，无新增异步定时器。

模块提供 `id / names / configure / pattern / cue / sources / presentationNodes`。`configure` 接受现行第二关规则，不修改输入。`cue` 根据音乐时间给出未来36步内的发射提示，视图应结合单式36步保护过滤提示。新难度显示层需给第二式的定时转向补变化前24步提示；原Easy绘制保持。
