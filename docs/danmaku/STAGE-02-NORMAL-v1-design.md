# 第二关 Normal 战斗设计 v1

2026-11-16，小典 / Codex；原型 (C) 2026 Carinoasd。

本页只记录新增独立战斗模块，统一入口、难度接续与浏览器验证由两关整合记录说明。Normal 是待真人试玩的候选，不冒称难度已验收。

运行模块：`source/plugin/gamecenter/games/_danmaku_stage02_draft/difficulty-normal-v1.js`。保持已有玩家操作、碰撞、五级成长、掉命补B、补给和图像／音乐。接收现行第二关 Easy 配置并克隆修改，原配置不变；同一配置重复应用不会重复追加敌人。

| 部分 | Normal 行为 |
|---|---|
| 道中 | 保留96秒、8秒首敌与原有收放结构；在38.5秒和76秒分别增加一对风侍，与守卫／齐阵形成组合，共124敌。新增护卫不额外发P／B。轻型一击破，风侍192、守卫600 HP；首发分别为出生后96／90／108步，预警30／36／36步。侧入轻型只首发，纵列轻型追加锁定三向；风侍穿插展开与一次锁定；守卫展开和锁定交替。 |
| Ⅰ 风廊 · 交叶迁径 | 六拍双侧叶束逐次交叉，通路随组在156／216／276／324等横坐标迁移；叶束投影到550px处时避让通路两侧62px，随后轻微弯曲。两次有缺口宽扇收句，尾段留白。384步一组。 |
| Ⅱ 花瓣舒展 · 错庭重瓣 | 三座花源轮换；主瓣展开48步后补反向缓瓣，快慢瓣错层开合。每组各花源的预留开口共同指向同一底部通路；后段两侧细叶收束。448步一组。 |
| Ⅲ 铃声回响 · 隔庭追响 | 侧铃主鸣后由对侧回声接答，下一次交换方向，末段中铃后接双侧回声和有缺口宽扇。主鸣192速度、回声140后84步提至184；每束在释放时锁定一次，之后不追踪玩家。480步一组。 |

Boss HP为6000／6600／7200。各式使用独立周期，持续读取现有Boss音乐时钟；换式不重启音乐。新式活动至少36步后才允许发弹，避免转式后没有识别窗口。`cue`仅预告未来36步内的计划事件，`sources`与实际源位共用同一事件描述；整合调用方应结合单式tick过滤被新式保护抑制的事件。

所有弹体使用现有整数运动状态，继承现有至少32px出生保护、B清弹及转式清场。阶段名按当前花庭主题编排，既有Easy三式不改。

局部Node检查：新文件语法通过，配置不改输入；六组900步Boss定点片段（每式音乐时钟390和2100各一组）重复执行快照相同，弹体运动字段与坐标均为整数。片段存活敌弹峰值Ⅰ93／87、Ⅱ91／88、Ⅲ59／59，未触及Boss360上限（道中另为256）。检查390至1800音乐步内的全部预告，均能对应36步内计划事件及非空源位。

另有三个900步无射击道中局部窗口，自479／2099／4499步开始，存活敌弹峰值98／93／48、敌机峰值16／15／7；攻击预警先于释放，配置重复应用不追加重复编队。这是发射／容量检查，不代表真实玩家击破与难度表现。

上述检查不等于无伤路线、真人Normal手感、音乐听感、浏览器显示、真实手机或完整两关验证；未自动整关自然通关。两关接续与资源状态检查由统一集成继续完成。
