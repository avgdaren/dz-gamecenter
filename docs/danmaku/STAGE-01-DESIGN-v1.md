## 一页概念

少女穿过悬在夜空的观测回廊，依次遇到巡星妖精、引光侍从和自动星仪守卫，抵达星环观测者所在的观测台。整体沿用已确认的二次元星空幻想：深蓝夜色、白银角色、少量暖金星仪，敌弹主体清楚可见。

第一关的小怪段定为**72秒草案**，随后衔接现有3秒Boss准备段，第75秒进入三阶段Boss战斗。初次体验依次学会：跟随编队输出、为拾取选择路线、诱导后离开瞄准位置、集中攻击精英、在混合压力中决定是否使用大招。关卡提供使用大招的机会，通路设计仍需支持不使用大招完成。

首轮内容为一关、三类小怪、八组基础编队、六名射手和两名精英，共40个敌人。节奏按固定时间轴推进，提前击破会减轻后续压力；敌人到时撤退，未击破小怪不判关卡失败，不因漏怪无限补波。精英属于短时小怪目标，不新增中Boss血条或独立转场。

## 三类小怪的玩法与造型

战斗小图建议采用与自机协调的像素画法，轮廓分别为横向小羽翼、竖向束翼与宽圆星仪。该画法属于本稿提案，正式背景画法留到场景制作时细化。敌人朝向下方的自机，保留二次元角色感；浅蓝／淡紫发色与既有浅金发自机形成区分。

| 工作名 | 外形与动作 | 玩法职责 | 建议画布／可见体量 |
|---|---|---|---|
| 巡星妖精 | 浅蓝短发，深蓝短裙、银白领边，一对向两侧张开的小羽翼；短促扇翼，左右飞行略侧倾 | 四只组成弧线编队，穿过上半场；每只只发一次三向慢弹，适合普通散射清理 | 48×48／约28×32 |
| 引光侍从 | 淡紫齐颈短发、窄长深蓝衣摆，羽翼贴身向下，手持短星杖；举杖蓄光后射击 | 从上方进入固定站位，锁定一次自机方向，连续发两轮三束针弹；集中火力可迅速处理 | 48×64／约28×46 |
| 星仪守卫 | 无人形面孔，深蓝菱形核心，暖金宽圆星仪和四片银金护板；环缓慢转动、发射前分段亮起 | 12秒精英窗口，缓慢横移，交替使用瞄准小扇与较宽固定扇形；奖励更集中 | 80×80／约60×60 |

所有尺寸均为480×640逻辑战场中的候选尺寸。身体核心要有明确实体，翅膀、星仪外环和光效不形成隐形碰撞。建议受弹核心半径依次为8／10／22，待实际画面与扫掠碰撞评审后确定。小怪身体接触按可见核心处理，采用与中弹一致的扣命／无敌优先级；不会让羽翼尖端触碰产生额外伤害。

普通小怪、射手和精英的击破时间目标依次为：基础火力持续对准约0.3～0.5秒、0.8～1.2秒、3～5秒。它们是后续调参目标，不是已测结果；HP与升级后的伤害在第二步共同确定。

正式素材清单先记为：妖精悬浮／左右飞行、侍从入场／蓄力／发射／退场、守卫待机／蓄力／受击；另需共用小型击破效果和强化物图标。四帧循环可作为首轮候选，实际动作数量在正式素材阶段按可读性收敛。

## 波次时间轴

时间以小怪段开始为0秒。区间左闭右开，出怪与开火时点固定，不依赖玩家是否击破上一组。

| 时间 | 出场和行为 | 玩家体验／奖励安排 |
|---|---|---|
| 0～4秒 | 穿过云门，无敌人、无敌弹；可移动与熟悉射击 | 一次简短操作提示，观察回廊方向 |
| 4～16秒 | 4秒左侧、10秒右侧各一组四只妖精；组内间隔0.55秒 | 先看懂弧线与三向慢弹；每组末位为强化掉落目标 |
| 16～20秒 | 停止新出怪，先前编队自然撤离 | 第一次拾取与换位；喘息不等于即时清除残弹 |
| 20～32秒 | 20秒射手站位x=116／364，26秒x=160／320；22秒左编队、28秒右编队 | 先让射手锁定，再离开原位；第一对左射手、第二对右射手为强化目标 |
| 32～36秒 | 停止新出怪与新攻击，消化残弹 | 第二次拾取，给精英留出准备时间 |
| 36～50秒 | 36秒守卫入场；40秒左编队、44秒右编队 | 首次集中攻击精英；守卫与编队末位提供强化目标 |
| 50～62秒 | 第二名守卫入场；52秒左射手、56秒右射手；54秒左编队、58秒右编队 | 复用已经见过的攻击，不加入新弹型；形成大招使用窗口，仍需验证不用大招的通路 |
| 62～68秒 | 不再出怪或开火；已有编队撤离、残弹自然离场 | 收束压力、收集已经生成的奖励；不以强制击杀结算漏怪 |
| 68～72秒 | 场上不再有小怪或敌弹，场景滚动减速 | 最后回收窗口；建议对已生成强化物缓慢吸取，机制在第二步实现与评审 |
| 72～75秒 | 清理小怪段临时对象，进入现有3秒Boss准备段 | 保留生命、当前火力和大招库存；可移动，准备段不射击、不消耗大招 |
| 75秒起 | Boss第一阶段激活，沿用后续三阶段结构 | 火力成长接入后重新核对Boss血量与阶段用时 |

## 出场路线与攻击规格

小怪实体的正常路线保持在上半场，完整可见身体不越过y=240；下半场留给观察、躲弹与收集。玩家仍能向上移动，进入小怪核心附近有身体碰撞风险，不把示意图里的上下分区当作强制移动边界。

**巡星妖精。** 左编队沿一条从(-24,56)到(504,56)的上半场弧线飞过，右编队水平镜像。首轮几何示意使用控制点(80,220)与(400,220)，生命周期5秒；每只入场1.35秒时向下发射一次三向扇形，角偏移为-16°／0°／16°。发射前0.45秒有翼根亮起的短提示，方向不瞄准自机；候选弹速108逻辑像素/秒、寿命5秒。

**引光侍从。** 从上方1秒降到y=120，锁定该时刻的自机方向并举杖蓄光。入场1.6秒和2秒发射两轮三束针弹，角偏移-10°／0°／10°，两轮使用同一锁定方向，之后不追踪。4.2秒开始退场，6秒离开；候选弹速114像素/秒、寿命5秒。提示用杖尖与短方向线，不铺满战场、不盖住敌弹。

**星仪守卫。** 1.6秒内从上方下降到约(240,132)，之后在中心两侧缓慢横移，10.4秒开始撤离，12秒离场。入场2.4／7.6秒发三向瞄准扇，发射前0.6秒锁定方向；5／10秒发向下的九向固定扇，半展开角48°，同样提前0.6秒提示。候选弹速102像素/秒、寿命5.5秒。两种攻击交替，不叠加激光、追踪弹或冲撞。

妖精使用圆弹，射手使用细针，守卫使用菱形短弹；用形状和运动共同区分危险。提示闪光、敌人受击闪烁和击破碎片需服从敌弹实体的可读性。大招演出不能改变这些发射时点；若消灭小怪，其后续攻击自然取消。

## 掉落位置与资源窗口

这一阶段只确定掉落目标和拾取机会，火力阈值、死亡损失、吸取范围和满级处理留给第二步。

八个编队各标记末位妖精，另标记两名教学段射手和两名守卫，合计12个重点掉落目标。普通目标暂按1份强化量、守卫按3份占位，合计16份是调参用草案，不代表必定取得或已确定升级阈值。实际需击破才生成，撤退敌人不补发，清掉敌弹也不产生奖励。

目标是让前两组编队提供第一轮成长机会，射手教学段推进下一次成长，精英奖励支持进入Boss前的补足。强化物建议使用带方形外框的星芯，外形区别于实心圆／针／菱形敌弹。先短暂悬浮再缓慢下落，并给出足够的可拾取时间；掉落在72秒前的回收与过期处理由第二步一起决定。

16～20秒、32～36秒为相对低压拾取段，已有敌弹仍然危险。68～72秒为脚本明确留出的无小怪／敌弹回收段；只吸取此前实际生成、尚未过期的物品，不给未击破敌人自动发放强化。拟保留当前标准2次大招作为前期平衡基线，小怪是否补充大招、携带上限和满库存处理均留第三步，不提前承诺额外补给。

## 场景与声音的设计接口

场景主题沿“云门 → 星灯回廊 → 悬浮星仪 → 观测台”推进。中央活动区域保持深蓝低对比，建筑、断柱与亮星灯以两侧和上方为主；场景滚动表现向上飞行，装饰不参与碰撞。36秒精英段引入星仪轮廓，62秒后减速，72秒停稳并衔接Boss。第四步再确定各层画法、接缝、滚动速度与正式图片。

BGM方向先定为轻盈流动的星空感：编队段清楚轻快，精英与混合段增加推进感，62秒后收束，72秒留出Boss登场衔接口。第五步制作时需允许提前死亡、暂停与任意恢复，不依赖某个敌人恰好被音乐重拍击破。事件清单预留：出场、蓄力、射击、受击、击破、掉落、拾取、升级、清屏、Boss登场。

基础界面先显示关卡名／当前段落、生命、火力和大招库存；不让教程遮罩打断前72秒。右下角少女正面展示继续沿用现有位置，最终页面布局留第六步统一优化。

运行`node tests/danmaku/check-stage01.cjs`核对时间轴、提示时长、轨迹占位和生成量。模型使用浮点曲线方便看路线；正式游戏必须另做固定逻辑步与JS/PHP一致实现，速度量化和真实瞄准也要重新验收。本稿中的几何示意不作为游戏规则文件导入。

已枚举0～75秒、60Hz示意：40个敌人、52轮发射、最多出生180颗敌弹；所有敌人均未被击破时，同屏敌人峰值8，固定自机参考位下敌弹峰值40。按寿命保留全部弹、不计算出界的保守峰值为45。小怪段暂留同屏10个敌人／96颗敌弹的设计上限，这是上限，不是目标；Boss段仍按其独立预算评估。最后一轮开火在61秒，敌人最迟64.65秒撤完、敌弹最迟66秒到期，68秒回收窗口前留有余量。
