# 天使弹幕祭 P0 可玩候选交接

日期：2026-11-10（北京时间） · 实现与验证：小典 / Codex。

本轮从规划推进到三个可玩弹型场景及本机 PHP 重播。候选可供试玩，极端压力预算仍未通过，不能标为 P0 全部验收或正式发布。

## 基线与范围

- 本地分支：`feat/danmaku-p0`，起点 `origin/main@76d226d12fed938d5592b60877d2fb9aadf8cdbd`；上一条水族馆分支保留。
- 原仓库检出不是截图中所有 18 款游戏的完整线上源码。Git 代理当时不可用；通过已连接 GitHub 读取的 main 最新提交标题与本地基线相符，但没有成功执行远端 fetch，不冒称线上完整基线已对齐。
- 只新增 `_danmaku_proto/`、`tests/danmaku/`、`docs/danmaku/`；不改公共 SDK、已有游戏或数据库，无数据库升级。
- 三个独立场景各最多 45 秒；标准 3 命／2 清屏，辅助 5 命／3 清屏和 3/4 弹速。几何自机／Boss、固定步模拟、扫掠碰撞、擦弹去重、暂停与恢复、基础触控、终局回放导出均已实现。
- Boss 在原型中只统计命中，不按血量结束。完整三阶段血条、正式计分、排行榜、每日／幽灵挑战、BGM 和正式素材都未实现。

## 试玩与复现

```powershell
python tests/danmaku/serve.py --port 8876
```

浏览器打开 <http://127.0.0.1:8876/>。启动脚本、规则验证、PHP 重播和基准命令见 [tests/danmaku/README.md](../../tests/danmaku/README.md)。本轮已启动本机隐藏预览进程，交付时可直接打开；服务停止后按上述命令重启即可。

选择练习会重置当前场景；标准／辅助仅在新局前切换。长按清屏键不重复消费，库存为 0 时按钮禁用。辅助与标准都是本地练习，不提交论坛成绩。

## 验证证据

| 类别 | 实际结果 | 适用边界 |
|---|---|---|
| 边界与编解码 | 35 项通过 | 有独立几何／时序断言，不以自测结果代替手感 |
| JS/PHP 正常回放 | 6 个固定终局＋200 组随机终局逐 60 步及终点状态一致 | 场景、辅助与正常输入；尚非完整标准 Boss 战 |
| 非法拒绝 | 两端拒绝 13 类记录 | 版本、速度、标记、额外客户端状态、长度和非终局等 |
| 真实浏览器回放 | 花瓣场 2,700 步，192 命中／1 受击／3 擦弹／1 清屏，PHP 复算相符 | 包含键盘移动、清屏及实际 UI 导出 |
| 正常原型计时 | 50 样本 p95=150.51ms，峰值内存 4 MiB | i9-14900HX、PHP 8.3.36 CLI、OPcache CLI 关闭，非线上 HTTP |
| 极端非合法压力 | 优化后单次 3783.47ms，超过 500ms | 明确 FAIL；未跑完整 50 样本，不能称 P0 性能门槛通过 |
| 实际 UI | 360px 窄屏、1280px 桌面、清屏、暂停／继续和相对拖动；花瓣／波浪各完成 45 秒 | 不是实际手机双指或全浏览器兼容验收 |

性能问题没有通过放弃 PHP 校验或相信客户端分数绕过。包围盒排除已减少不必要的 min/max 调用，但极端夹具仍超预算。可继续做玩法评审；进入完整战斗与论坛接入前，应进一步优化规则／验证成本，并用最长合法完整战斗记录补测。当前不自动批准进入 P1。

定点 Q=64，敌弹／自机位移有限，扫掠包围盒之后再做窄相位：保守按相对单轴步长≤1024、最大合并半径 1984 计算，窄相位端点单轴绝对值≤3008；叉积平方上界 `(2×3008×1024)^2≈3.80×10^13`，低于 JS `2^53-1`。坐标限位、方向表范数与输入速度圆均另有检查。PHP 使用相同整数表与除法方向，不运行浮点三角函数。

3. 实际手机双指／指针取消、后台切换和窄屏长时游戏仍需补验。
4. 随后再接完整三阶段及计分。P2 才接平台凭证、普通榜单及 4 worker 混合负载；P3 再制作正式美术／音频。
