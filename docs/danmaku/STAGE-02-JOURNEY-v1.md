## 已接通的流程

| 流程 | 当前行为 |
|---|---|
| 标题与开场独白 | 两句独白交代晨星异常和追寻前辈，手动继续或跳过 |
| 花庭道中 | 使用现有三类小怪、编队、攻击、受击／击破与掉落，首版一遍208.84秒音乐 |
| 道中收束 | 停止新出敌，末段收取掉落；关尾结算未拾取掉落，再清除残弹／自机弹 |
| 与铃羽相遇 | 进入五句短对白，背景停留、战斗和音乐暂停 |
| 铃羽登场 | 对白结束后开始Boss音乐，保留6.5秒停顿与立绘演出；之后场景用2.5秒平滑恢复前进 |
| 三阶段战斗 | 风廊、花瓣舒展、铃声回响，以击破推进；转场2秒，音乐不断开重播 |
| 击破收尾 | 清除残弹与自机弹，0.8秒淡出Boss音乐，保留1.25秒收束 |
| 战后对白与完成 | 四句短对白给出旧航路线索，随后显示完成状态与击破／擦弹等本轮数据 |
| 失败与重试 | 可从头重试；到过铃羽后，可用抵达时的资源从铃羽重试 |

道中的生命、原始火力值、B库存及统计继承到Boss，不套用旧练习入口的满级火力默认值。检查点保存的是抵达铃羽时的资源副本，失败后不会把损失写回检查点。重新开始整关会回到3生命、1级火力、2B和开场独白。

场景速度仍为已确认v3：道中4.9单位／秒；Boss入场停6.5秒后，2.5秒平滑恢复至2.45。对白阅读时间是额外的暂停时间，不消耗这6.5秒演出。

## 叶片、铃花的实战融合

- 源PNG不改，不重新生成图片。保留用户认可的粉色花瓣、青绿叶片与金白铃花风格。
- 叶片显示高度从约21px收至17px；铃花从20px收至15.5px，半径较大的实例稍增。轮廓改轻，降低小尺寸贴纸感；花瓣保持18px基准。
- 出生后10步轻微展开到正常大小，中心保持实色；朝向跟随原速度并有小幅轻摆。简化动态关闭展开和轻摆，保留战斗运动。
- 从实际敌弹出生坐标记录短暂发射痕迹，按同一发射点合并成轻风圈与流痕，连起小怪／铃羽施法动作和飞行中的花叶。仅作显示，不改出生位置。
- 铃声回响阶段的三个发射点改为铃花光源，通过细风纹与铃杖相连，在阶段转场时显现；主弧和回声从这些实际发射点散出。人物施法反馈改为跟随实际发射事件。
- 控制器、判定、HP、现有弹道和音乐cue表不变。源点、展开等为展示数据，不加入旧版判定或成绩契约。

源图仍见 [花叶素材与提示词](art/stage02-projectiles-v1/PROMPTS.md)。既有小怪与铃羽为单姿态源图配运行时变形，不将本轮描述成新增原生多帧图集。
