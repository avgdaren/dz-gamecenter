## 本轮行为

集中时显示红白中心、深色底、外环和四向短线，普通状态隐藏。真实命中半径仍为3，外环与短线只用于定位；判定点最后绘制，独立于自机无敌闪烁和大招特效。各练习模式也使用这套更清晰的显示。

大招暂名“星翼绽放”。X／空格或“大招”按钮触发，库存不足或冷却时不释放；键盘长按不连发，冷却期间的操作不排队。开场准备和阶段转场不能释放，不补库存。

| 项目 | 当前规则 |
|---|---|
| 初始库存 | 标准2枚；辅助3枚 |
| 携带上限 | 3枚，贯穿小怪段与Boss |
| 补充 | 两名星仪守卫各在实际击破后掉落1个金色B；撤退不发放 |
| 满库存拾取 | 消耗该B，转500分；不增加自机火力 |
| 死亡 | 不补充或重置大招库存，仍沿用掉命降一档火力 |
| 伤害 | 释放当步造成一次300点全屏伤害；不持续重复伤害 |
| 清弹 | 当步清除现有敌弹，并持续90逻辑步，即1.5秒 |
| 护身与冷却 | 各120逻辑步，即2秒；暂停冻结，转场正常流逝 |

伤害只作用于当前场内的活小怪或当前Boss阶段，按剩余HP裁剪；不命中未来／场外敌人，不溢出到下一阶段。满血360HP的星仪守卫受大招后剩60HP。大招击破的实际敌人保留正常击破分与掉落；单纯清除的敌弹不生成P／B，不产生擦弹奖励。大招伤害与普通子弹命中次数分别统计，Boss有效伤害仍计入原伤害分。

B复用P的悬浮、到期、吸取和拾取规则；68秒汇聚及转场只回收已经生成且仍有效的道具。补给总来源固定为两名守卫，最高携带量始终为3。新规则分数上界为321300，包含最多两个B各500分的溢出；旧版320300上界保持不变。

特效为金蓝扩张星环、八角星轮廓和羽翼线条，避免整屏白闪。可勾选“简化大招特效”，减少为护身小环与名称，默认遵循系统减少动态效果偏好；该开关只影响绘制。库存、冷却、补给说明和结算溢出分随玩法接入，整体UI重排留到后续阶段。
