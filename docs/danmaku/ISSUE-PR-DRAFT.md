## Issue 标题

天使弹幕祭 P0：三种弹型练习原型与确定性回放

## Issue 正文

游戏中心计划新增单人弹幕射击。先制作花瓣、瞄准连射、交错波浪三个独立 45 秒练习场，验证操作、判定可读性和 PHP 重播成本，再进入完整 Boss 战。

交付包括键盘／基础触控、标准／辅助、清屏与无敌、擦弹、暂停、回放导出、本机 PHP 重算及跨语言验证。P0 不上架、不记积分、不改数据库。验收清单和详细参数见随分支提供的 docs/danmaku 规格与交接说明。

## PR 标题

feat(danmaku): 添加三种弹型练习场与本机回放候选

## PR 正文

新增三个可直接在浏览器练习的 45 秒弹型场景，包含移动、慢速、自动射击、清屏、擦弹和暂停。每步记录合法输入，由独立 PHP 实现重算同一份规则，用于验证之后接入论坛的可行性。

35 项边界／往返／拒绝检查、6 份固定终局、200 组随机终局差分和 13 类两端非法拒绝通过；真实浏览器的 2,700 步回放通过 PHP 复算。正常原型 50 样本 p95=150.51ms；极端非合法 360 弹压力夹具单次约 3.8 秒，仍超预算，故本 PR 仅为可玩候选，不能视为 P0 完整验收。

未验／未实现：实际手机双指、完整三阶段标准局、论坛开局／榜单／worker 混合负载、正式美术和音频。无数据库升级，未部署；所有代码位于扫描忽略的原型目录及测试目录，公共 SDK 和既有游戏不变。
