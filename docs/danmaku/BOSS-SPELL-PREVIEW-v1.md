## 分镜与时序

| 节点 | 逻辑帧／正常速度 | 本次画面 |
|---|---|---|
| 收束蓄势 | 0–17／0–0.30秒 | 场景压暗、星仪／花风印浮现，小型Boss保持在场 |
| 立绘切入 | 18–35／0.30–0.60秒 | 大立绘从左进入，斜向符纹开始流动 |
| 招名宣告 | 36–79／0.60–1.33秒 | 40–54帧招名渐入；62帧默认定格，法阵／立绘／招名同屏 |
| 立绘退场 | 80–119／1.33–2秒 | 立绘渐退，88帧开始缩移招名，纹带112帧前退尽 |
| 战斗落位 | 120–240／2–4秒 | 立绘与纹带消失，右上招名与低对比法阵保留；仅为示意 |
| 换式／最终收尾 | 本招结束事件，后续实施 | 换式交叉过渡背景、退休旧招名，实体保持；最终击败另收束法阵并接战后对白 |

两位Boss共用时序、进退曲线与招名层级。观测者用冷蓝／淡金星仪、星轨和星尘；铃羽用浅青／粉金五瓣几何、三铃与花瓣。复用已有立绘，源PNG保持原样，几何与纹带用原生Canvas新写，未复制参考仓库的游戏图像／ANM资源。参考依据和已观看视频范围见[计划](BOSS-SPELL-PRESENTATION-PLAN-v1.md#参考核对)。

招名采用既有500字重离线衬线子集，分前缀／主名；铃羽无前缀时显示式号。主名独立于框：宣告在右下，之后收至右上持续可读。HUD上缘另留27像素。完整字体OFL与Adobe版权已内嵌。

## 图层与接入约束

由后至前：原背景 → 主题暗色／柔光 → 大法阵／纹带 → 大立绘与下缘融合 → 少量星尘／花瓣 → 小型Boss与自机／判定点 → 独立招名 → HUD。无镜头震动；闪光透明度最高0.13，止于自机上方。简化动态禁用旋转、纹带漂移、粒子位移和闪光，保留渐变与招名阅读。

正式接入时危险弹幕、预警、自机判定点和必要读数应在主题背景／立绘上层。已确认v6自机翼形大招框保持；本短样未加载大招，实际避让／弹幕可读性留给第3–5步。不要把此渲染器直接作为战斗引擎，也不要随参考代码增加换招等待。
